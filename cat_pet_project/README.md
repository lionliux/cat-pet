# 🐱 加菲猫桌面宠物

一个可爱的 Windows 桌面宠物程序，基于 Python + Tkinter 开发。

## ✨ 功能特性

- 🖼️ **透明窗口**：无边框、背景透明，完美融入桌面
- 📌 **始终置顶**：默认置顶显示，随时可见
- 🖱️ **左键拖动**：按住鼠标左键自由移动位置
- 🎯 **点击互动**：点击猫咪随机触发跳跃、压扁、抖动三种动画
- 💬 **对话气泡**：互动时显示有趣的中文对话气泡（白色不透明背景）
- 🔍 **滚轮缩放**：鼠标滚轮调整猫咪大小
- 📋 **右键菜单**：调整大小、切换置顶、退出程序
- 🐾 **多形态切换**：互动时随机切换不同猫咪形象

## 🚀 快速开始

### 方式一：直接使用打包好的 EXE（推荐）

如果你已经有了 `加菲猫桌宠.exe`，直接双击运行即可，无需安装任何东西。

### 方式二：从源码打包

1. 确保已安装 **Python 3.8+**
2. 双击运行 `一键打包.bat`
3. 等待打包完成，EXE 文件生成在 `dist` 文件夹中
4. 双击 `加菲猫桌宠.exe` 运行

### 方式三：直接运行 Python 脚本

```bash
# 安装依赖
pip install pillow

# 预处理图片（可选，推荐）
python preprocess_images.py

# 运行桌宠
python cat_pet.py
```

## 🎮 使用说明

| 操作 | 功能 |
|------|------|
| 左键按住拖动 | 移动猫咪位置 |
| 左键点击 | 触发互动动画 + 对话气泡 |
| 鼠标滚轮 | 放大/缩小猫咪 |
| 右键点击 | 打开功能菜单 |

### 右键菜单

- **关于桌宠**：查看版本和功能说明
- **调整大小**：手动输入缩放倍数（0.1~2.0）
- **放大/缩小**：快速调整尺寸
- **切换置顶**：开启/关闭窗口始终置顶
- **退出**：关闭桌宠程序

## 🎨 自定义配置

### 修改对话文本

打开 `cat_pet.py`，找到 `DIALOG_TEXTS` 列表，添加或修改你喜欢的台词。

### 调整动画参数

在 `cat_pet.py` 顶部的配置区域修改：

```python
DEFAULT_SCALE = 0.3        # 初始大小
JUMP_HEIGHT = 60           # 跳跃高度
SHAKE_DISTANCE = 6         # 抖动幅度
ANIMATION_SPEED = 20       # 动画速度（越小越快）
BUBBLE_DURATION = 3000     # 气泡显示时长（毫秒）
```

### 替换/添加猫咪图片

1. 准备猫咪图片（PNG透明背景最佳）
2. 放入 `assets` 文件夹，命名为 `cat1.png`、`cat2.png`、`cat3.png`...
3. 如果图片有背景，先运行 `python preprocess_images.py` 自动抠图
4. 打开 `cat_pet.py`，修改 `IMAGE_FILES` 列表添加更多图片
5. 重新打包或直接运行

> 💡 **抠图小贴士**：自动抠图对纯色背景效果好。如果是复杂背景，建议使用在线AI抠图工具：
> - [remove.bg](https://www.remove.bg/)
> - [稿定设计抠图](https://www.gaoding.com/koutu)
>
> 抠好的透明 PNG 直接替换 `assets` 里的图片即可，效果会更精致。

## ❓ 常见问题

### Q: 窗口有黑色背景，不是透明的？
A: 透明窗口功能是 Windows 专属的，请确保在 Windows 系统上运行。

### Q: 猫咪图片显示不出来？
A: 检查 `assets` 文件夹是否与程序在同一目录，图片文件名为 `cat1.png`、`cat2.png`、`cat3.png`。

### Q: 怎么让桌宠开机自启？
A: 按 `Win + R`，输入 `shell:startup`，把 EXE 的快捷方式拖进去即可。

### Q: 怎么退出程序？
A: 右键点击猫咪，选择「退出」。

### Q: 打包后 EXE 运行报错？
A: 确保打包时使用了 `--add-data "assets;assets"` 参数，或者手动将 `assets` 文件夹复制到 EXE 同目录。
